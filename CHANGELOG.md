# Changelog

## 0.1.0

First release.

- `OpenBeamClient`: device sign-in, sessions (create, list, read, end), account, play time, simulators, showcase scenes.
- `OpenBeamPlayer`: mounts the OpenBeam Cloud player in an iframe; `state`, `relaunch` and `latency` events; keyboard lock for fullscreen.
- `openbeam-player.min.js`: the player for a `<script>` tag.
- Quickstart example app.
